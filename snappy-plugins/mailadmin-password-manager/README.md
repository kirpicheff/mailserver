# Плагин SnappyMail: Смена и сброс пароля через MailAdmin API

Плагин для почтового клиента SnappyMail, добавляющий возможность:
1. **Смены пароля из настроек авторизованного пользователя** (разделы Settings -> Accounts -> Change Password).
2. **Сброса забытого пароля с экрана входа** ("Забыли пароль?"). Одноразовый 6-значный код отправляется на этот же почтовый ящик, и пользователь может прочитать его в уже авторизованном клиенте.
3. **Блокировки смены пароля** для выбранных администратором ящиков (Blacklist).
4. **Безопасного сохранения нового пароля** в PostfixAdmin через REST API панели MailAdmin.

## Установка плагина в SnappyMail

1. Скопируйте папку плагина в директорию плагинов вашей установки SnappyMail:
   ```bash
   cp -r snappymail-plugin-mailadmin-change-password /path/to/snappymail/data/_data_/_default_/plugins/mailadmin-change-password
   ```
2. Откройте панель администратора SnappyMail (например, `https://your-domain.com/?admin`).
3. Перейдите в раздел **Plugins** (Плагины).
4. Найдите плагин `mailadmin-change-password` и включите его (поставьте галочку **Enable**).

## Настройка плагина в панели администратора SnappyMail

Кликните на название плагина в списке для открытия окна настроек:

1. **MailAdmin API Base URL**: Укажите URL вашей панели MailAdmin (например, `http://127.0.0.1:8080` или `https://mailadmin.yourdomain.com`).
2. **MailAdmin API Token**: (Рекомендуется) Статический токен для авторизации (`ma_tk_...`), сгенерированный в панели MailAdmin со scope `mailbox:password`. При использовании токена логин и пароль ниже будут проигнорированы.
3. **MailAdmin Username (Fallback)**: Логин администратора MailAdmin (используется только если не указан токен).
4. **MailAdmin Password (Fallback)**: Пароль администратора MailAdmin.
4. **Запрещенные ящики (Blacklist)**: Список e-mail ящиков (по одному на строку), которым ЗАПРЕЩЕНО менять пароль.
   *Пример:*
   ```text
   ceo@domain.com
   boss@domain.com
   info@domain.com
   ```
5. **Время жизни кода (мин)**: Время действия 6-значного кода подтверждения (по умолчанию `15` минут).

## Проверка работы

### 1. Сброс пароля на странице логина
- На странице входа SnappyMail под кнопкой «Войти» появится ссылка **«Забыли пароль?»**.
- При клике откроется окно с вводом e-mail.
- Плагин сгенерирует 6-значный код и отправит письмо на этот адрес.
- Пользователь вводит полученный код и новый пароль -> плагин авторизуется в MailAdmin API и устанавливает новый пароль.

### 2. Смена пароля авторизованным пользователем
- В настройках SnappyMail (**Settings -> Accounts -> Change Password**) пользователь вводит старый и новый пароль.
- Если ящик не в черном списке, плагин обновит пароль через MailAdmin API.
